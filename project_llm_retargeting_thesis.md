Project: houdini-apex-handbuild (https://github.com/ysk424/houdini-apex-handbuild, video https://youtu.be/QuLa9eOgQNc, published 2026-05-02).

User's framing of what matters most in this release: the demonstration that a code-capable LLM over MCP can perform skeletal retargeting work between mismatched rigs (Cascadeur 101-joint canonical CC4 ↔ low-poly 80-joint character). The APEX hand-build procedure is the vehicle; LLM-driven retargeting is the headline.

**Why:** Retargeting between non-matching skeletons is normally per-pipeline manual labor. Showing an LLM can do it from prompts + MCP tools generalizes far beyond Houdini APEX — it applies to anyone doing animation work with mismatched skeletons. That generalization is what the user wants the wider audience to absorb.

**How to apply:** If user returns to this project (follow-up videos, additional docs, related demos), keep the retargeting angle prominent. When suggesting future content or extensions, prioritize ideas that further demonstrate or generalize LLM-driven animation work over ideas that go deeper into APEX-internals minutiae.
